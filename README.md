# campus-portal-design
Mobile-optimized SharePoint portal for student exchange and study abroad programs.

## Overview
A student exchange and study abroad portal site built using Microsoft SharePoint and Microsoft Teams. It is designed and optimized for both desktop and mobile views to ensure quick access to essential resources on smartphones.

## Key Features
- **Program & Blog Links:** Quick navigation to overseas dispatch and exchange program blogs.
- **Administrative Links:** Direct access to important procedures such as JASSO scholarship applications.
- **Global Tools:** World Clock integration for international program destinations.
- **Media Integration:** Embedded news, weather widgets, and video resources.

## Mobile Optimization Highlights
- **Carousel Hero Layout:** Converted hero links into a carousel slider to reduce excessive vertical scrolling on mobile devices.
- **Responsive Layout:** Adjusted section layouts to ensure widgets remain compact and easy to read on smaller screens.

## About This Portal
This sample portal demonstrates:
- Information architecture for international programs  
- Document management using Microsoft 365  
- Workflow design (Teams, Planner, Approvals)  
- Best practices for global mobility communication  

It is intended as a model for universities seeking to modernize or redesign their study abroad support systems.
